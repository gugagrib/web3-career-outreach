# W3 / Ledger — Web3 Career Outreach

A public work log for a Web3 growth and product-research portfolio. This repository records the structure and thinking behind the W3 / Ledger site built on September 1, 2026.

> Turn protocol curiosity into traction.

## What was built

The site turns hands-on research across RISEx, Variational Omni, Ink Points, and Lighter into a clear international-career narrative. It combines an editorial portfolio, a read-only project activity tracker, an outreach template lab, and a practical GitHub operating note.

The live preview is available at [W3 / Ledger](https://3000-i2wkd33377t3d9bzjpqyf-02667690.us1.manus.computer). The preview URL is a development environment and may not be permanent.

## Site map

| Section | Purpose |
|---|---|
| Hero / Positioning | Establishes the growth, product, and community lens. |
| Read-only Tracker | Shows public-source status for RISEx, Variational Omni, and Ink Points without wallet or trading-key access. |
| Project Signals | Documents four protocol observations and links to official sources. |
| Outreach Lab | Provides founder and recruiter message starters with a copy action. |
| GitHub Operating Note | Explains how public work becomes verifiable through clean repositories, case studies, tests, and review. |

## Safety and scope

This is a documentation and portfolio project. It does not promise an airdrop, points allocation, employment outcome, or financial return. The tracker is read-only and does not connect to a wallet, hold private keys, automate trading, or simulate user activity. Public claims should be checked against the official source before use.

No passwords, access tokens, seed phrases, private keys, environment files, browser cookies, logs, or private identity material belong in this repository.

## Design direction

W3 / Ledger uses an editorial field-note system: bone paper, ink black, signal lime, mono metadata, hard-edged modules, asymmetric composition, and annotation cues that make the work feel like an active operator’s notebook rather than a generic portfolio.
